# 意图识别

本文是第八部分的第一篇正文，它讲清意图识别如何把用户问题归到预设类别。全文分为五节，前两节讲意图识别的目标与三层结构，中间两节讲覆盖层与实现，最后一节给出反例与练习。

## 一、意图识别要解决什么

### 1.1 为什么先要分类

用户的问题背后往往藏着一个明确的目的。有人想问政策，有人想查订单，有人想投诉，有人只是打招呼。系统如果不知道用户的意图，就无法决定后续该做什么：查订单需要调用订单工具，问政策需要检索知识库，打招呼则不需要任何外部资源。意图识别因此是整条链路的第一步决策。

本项目把意图划分为 14 个类别，包括问候、闲聊、政策问答、订单查询、物流、退款、退货换货、取消订单、商品咨询、推荐、优惠券、投诉、转人工与越界。每个类别都对应一个枚举值，例如 `faq_policy` 表示政策问答，`order_inquiry` 表示订单查询。

### 1.2 分类的产物

意图识别的产物是一个 `IntentResult`，它包含标签、置信度、理由与提示词版本四个字段。系统不只需要标签，还需要理由与置信度，因为后续的覆盖层与路由都可能用到它们。理由字段记录了这次判断的依据，便于排障；置信度字段则让系统知道这次判断有多可靠。

## 二、三层结构

本项目的意图识别由三层组成，它们按优先级协作。

第一层是**大模型分类**。系统把用户问题交给大模型，要求它输出一个 JSON 格式的意图标签。这是生产路径的主干，因为它能够处理措辞多样、无法穷举的表达。

第二层是**规则兜底**。`app/agents/nodes/intent.py` 中的 `rule_based_intent` 维护了一张关键词表，它按顺序匹配用户问题中的关键词，命中即返回对应标签。这张表的存在有两个目的：一是当大模型不可用或输出无法解析时，系统仍然能够给出一个意图；二是为覆盖层与测试提供一个确定性的基线。这张规则表在 100 条测试集上的准确率只有 51%，这个数字不是缺陷，而是一份证据：它证明只靠关键词规则远远不够。

第三层是**高置信覆盖层**。它在模型或规则给出标签之后再做一次纠偏，只处理那些稳定但易混的中文短语。

## 三、覆盖层为什么存在

中文客服里有一批短语，模型和规则都容易判错，而且错得有规律。最典型的是"人工审核一下退款"。这句话字面上包含"退款"，模型很可能把它判成退款意图；但它真正表达的是"我要找人处理"，正确的标签是转人工。类似的例子还有政策问法与退换货的混淆："七天无理由怎么算"问的是政策规则，而"这个杯子能退吗"问的是具体能否退换。

`app/agents/nodes/intent_overlay.py` 中的 `high_precision_intent` 正是为处理这类歧义而写。它按优先级判断：先看是否越界或注入，再看是否含转人工短语，再看是否只是问候，之后依次判断投诉、物流、取消、优惠券、退款、退换货等。它只在规则足够确信时才返回标签，否则返回 `None`，把判断权交还给大模型。这种"只在确信时介入"的策略，让覆盖层既能纠偏，又不会越权覆盖模型的合理判断。

这里有一条边界必须讲清：覆盖层针对的是稳定的短语模式，例如"转人工""人工客服"，它**不是**按测试用例的编号写死答案。读者在面试中应当主动说明这一点，否则很容易被怀疑是在"对答案"。

## 四、本项目的实现与消融

`IntentClassifier.classify` 先把规则结果作为兜底算好，再尝试调用大模型。如果模型返回可解析的 JSON，系统就采用模型的标签，并调用 `_maybe_overlay` 做一次覆盖层纠偏；如果模型调用失败，系统就采用规则结果，同样经过覆盖层。`_maybe_overlay` 在覆盖层改动了标签时，会把置信度提升到至少 0.93，并在理由里追加一条 `overlay:xxx` 记录，让这次纠偏可追溯。

项目还提供了一个开关 `apply_overlay`。当它设为 `False` 时，系统跳过覆盖层，用来做消融对比。评测数据显示：关键词规则的准确率为 51%，无覆盖层的大模型版本 v1 为 85%、v2 为 86%，仅覆盖层单独作用为 100%，而生产路径的 v3 加覆盖层为 100%。这组消融说明了两件事：大模型把整体从 51% 拉到了 85% 以上，覆盖层则补上了最后那段由稳定歧义造成的差距。

## 五、反例与练习

假设系统去掉覆盖层，只保留大模型分类。用户说"人工审核一下退款"，模型很可能把它判成退款意图，于是系统走了退款流程，而用户其实是想转人工。这类错误不会让系统崩溃，却会让用户体验变差，甚至让用户以为自己的诉求被误解。这个反例说明，覆盖层处理的正是模型在稳定歧义上的系统性偏差。

本部分的练习有两项。第一项是识别歧义：读者应说明"人工审核一下退款"为什么容易被判成退款，正确标签应当是什么。第二项是解释口径：读者应说明意图识别的 100% 包含覆盖层，并说明覆盖层不是按测试用例写死。

本篇对应的指标是第 11 部分"评测体系"中的意图准确率。规则基线 51%、无覆盖模型 85% 到 86%、生产路径 100%，这组数字是意图识别能力的完整证据链。读者在阅读下一篇时，可以对照理解意图如何进一步转成处理策略。
